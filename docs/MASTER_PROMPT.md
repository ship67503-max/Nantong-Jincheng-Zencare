# JCZCARE Master Prompt

## Project Mission
JCZCARE is the official independent website for Nantong JINCHENG ZENCARE Technology Company, a pet care absorbent product source factory serving global B2B buyers.

The website exists to build trust, explain manufacturing capability, educate buyers, and convert qualified OEM/ODM inquiries for pet pads, absorbent paper sheets, pet care pads, glove wipes, pet waste bags, charcoal pet pads, adhesive pet pads, and related absorbent care products.

The long-term mission is to become a high-trust digital business center for overseas brands, distributors, wholesalers, importers, supermarkets, cross-border sellers, and channel partners looking for stable factory-side pet care product development.

## Core Positioning
JCZCARE should be presented as:

- A source factory, not a trading website.
- A B2B OEM/ODM partner, not a retail store.
- A professional manufacturer with product planning capability.
- A long-term supply and development partner for overseas buyers.
- A clean, high-end, modern, trustworthy pet care manufacturing brand.

## Primary Roles

### Website Owner
Defines business direction, target markets, product priorities, buyer needs, reference websites, product photos, factory videos, and final approval.

### AI Development Assistant
Supports implementation, documentation, SEO planning, content generation, quality checks, build verification, Git operations, and deployment support.

### Developer Role
Maintains source code quality, routing, build stability, responsive layout, SEO infrastructure, performance, and deployment reliability.

### SEO Role
Maintains metadata, canonical URLs, schema, sitemap, robots.txt, internal linking, keyword expansion, AI search optimization, and Google Search Console readiness.

### Brand Content Role
Creates professional B2B copy that is clear, policy-safe, market-aware, and aligned with pet care manufacturing credibility.

## Development Workflow

1. Understand the business requirement.
2. Inspect the current code and content before editing.
3. Identify the smallest safe change.
4. Modify only the files required by the task.
5. Preserve existing design direction unless explicitly asked to redesign.
6. Run local checks when code or build configuration changes.
7. Build before deployment.
8. Commit with a clear message.
9. Push and confirm deployment when requested.
10. Report what changed, what was verified, and any remaining risk.

## Coding Principles

- Prefer simple, maintainable React components.
- Keep source data structured when possible.
- Avoid hardcoded duplication when a shared data source is more reliable.
- Preserve routing behavior and SEO metadata.
- Do not introduce unnecessary dependencies.
- Keep visual changes scoped and intentional.
- Keep build output out of Git.
- Keep large raw media out of Git unless explicitly managed through external storage or Git LFS.

## SEO Philosophy
Every public page should help one of three goals:

- Build factory trust.
- Rank for commercial B2B search intent.
- Convert a qualified buyer into an inquiry.

SEO must be implemented as infrastructure, not as afterthought text. Pages should have clear titles, concise descriptions, canonical URLs, structured data, internal links, useful headings, and search-aligned content.

## Content Philosophy
JCZCARE content should sound professional, specific, calm, and buyer-focused.

Avoid exaggerated claims, risky advertising language, vague marketing filler, and unsupported guarantees. Prefer practical manufacturing language:

- OEM/ODM support
- Product planning
- Sample development
- Private-label packaging
- Quality checks
- Production coordination
- Export-oriented B2B supply

## Design Philosophy
The website should feel like a high-end creative agency site applied to an industrial pet care manufacturer.

Design should be:

- Fresh and premium.
- Dark green, clean, modern, and controlled.
- Spacious but not empty.
- Visual-led, using real factory/product imagery where possible.
- Sophisticated in motion, not cheap or bouncy.
- Built for desktop-first B2B browsing while remaining responsive.

## Conversion Philosophy
The website should guide buyers toward clear actions:

- Contact the factory.
- Request a product plan.
- Learn about OEM/ODM capability.
- Review product categories.
- Understand quality control.
- Explore factory trust signals.

CTAs should be direct, helpful, and relevant to B2B decision making.

## Long-Term Operating Principle
Every change should make the website more trustworthy, easier to understand, easier to maintain, easier to rank, or easier to convert.
