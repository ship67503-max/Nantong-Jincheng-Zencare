# Website-ready product visuals

This folder contains 15 supplied product photographs processed into three 16:9 variants each:

- `*_A_lifestyle.jpg` - warm modern home / pet-care atmosphere
- `*_B_studio.jpg` - high-key commercial studio presentation
- `*_C_oem.jpg` - cool neutral OEM/ODM catalog presentation

All deliverables are 1920x1080 JPEG files. The source product pixels remain the foreground; processing is limited to conservative edge cleanup, exposure/color balancing, sharpening, and low-frequency background atmosphere. Packaging graphics, labels, logos, colors, folds, seams, and material textures are not regenerated.

The three AI-generated background plates used for the controlled edge blend are in `backgrounds/`. The exact source-to-output mapping is in `manifest.tsv`.
